# Handyfeeling API code examples and demos

A collection of code samples and demos showcasing the use of various Handyfeeling APIs.

Most of the demos are small web-pages that need to be served from a http-server.

## Install

The root package is configured with the http-server package.

Install the package by running the following command in the root folder of this repo.

```bash
 $ npm install
```

## Start server

Start the http-server with:

```bash
  $ npm run start
```

An index of available demos will be available at: http://127.0.0.1:8080/index.html
