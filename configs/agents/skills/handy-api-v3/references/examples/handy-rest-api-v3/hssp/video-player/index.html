HSSP video player integration

You need to provide an ApplicationID issued for the Handy API to run this demo. You can issue an ApplicationID by creating a developer account on HandyFeeling User web.

This demo demonstrates how you can use the HSSP protocol to play scripts on the device synchronized with video.

The video player events are integrated with the HSSP API commands to control the device.

Play, stop, seek, buffering and play back speed changes in the video player will be synchronized with the device.
