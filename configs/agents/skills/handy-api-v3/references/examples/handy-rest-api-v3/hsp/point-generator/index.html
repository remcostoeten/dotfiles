HSP points generator

You need to provide an ApplicationID issued for the Handy API to run this demo. You can issue an ApplicationID by creating a developer account on HandyFeeling User web.

This demo demonstrates how you can use the HSP protocol to stream movement data to a device.

Press setup to initiate a new HSP session.

The points generator generates the specified number of points, with the interval and amplitude specified, and sends it to the device. Press Add points to generate some initial points and press Play to start playing them.

The generator will generate a new set of points and forward them to the device upon receiving a threshold or starving notifcation over SSE.
