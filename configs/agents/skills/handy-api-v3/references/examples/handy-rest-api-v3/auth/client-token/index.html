Client-token demo

You need to provide an ApplicationKey issued for the Handy API to run this demo. You can issue an ApplicationKey by creating a developer account on HandyFeeling User web.

This demo demonstrates how to issue client-tokens. Client-tokens can be used to authenticate a client with the Handy API v3, optionally restricting the client's access to a specific device connection key, client IP and request origin.

You can read more about client-tokens in the Handy API v3 documentation.

Alos check out the Handy API v3 client token issuer endpoint specification.
