SSE: Device events

You need to provide an ApplicationID issued for the Handy API to run this demo. You can issue an ApplicationID by creating a developer account on HandyFeeling User web.

This demo showcases how you can use the SSE endpoint to receive real-time device updates from the server. This demo listens for all device events.

The UI is updated with the received device events. Events are added to the events-list as they are received.

You can trigger button events by pressing the buttons on your device. Only button events that trigger a device state change is forwarded.
