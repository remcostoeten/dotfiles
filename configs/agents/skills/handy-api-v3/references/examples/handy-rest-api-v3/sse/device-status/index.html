SSE: Device status

You need to provide an ApplicationID issued for the Handy API to run this demo. You can issue an ApplicationID by creating a developer account on HandyFeeling User web.

This demo showcases how you can use the SSE endpoint to receive real-time device updates from the server.

The UI is updated with the received device connected status update.

If you unplug your device the status should change to Offline after a few seconds. If you plug it back in the status should change back to Online.

If you turn off the wifi mode (eg. switch to bluetooth only mode or offline mode) the status should change to offline immediatley.
