# Dictionary-entry README pitches

Use this shape only when the project name is a real word whose meaning fits the project. Match the register of these entries; they are from Remco's own projects.

**Skriuw** *(noun)*
/skrɪu̯/, *Frisian, "to write."*

A local-first desktop application for writing and organizing thoughts. Built with Tauri 2.0, Next.js 15, and InstantDB, **Skriuw** blends note-taking and task management into a single, fast, and private workspace. It supports Markdown editing, offline access, real-time sync, and cross-platform support for Windows, macOS, and Linux.

---

**Satio** *(noun)*
/ˈsa.ti.oː/, *Latin, "to sow, plant, or bring forth."*

A lightweight CLI seeding tool for **Skriuw** that plants Markdown notes into the database. Designed for initializing projects, testing content structures, or quickly populating demo environments with example data.

---

**Servo** *(noun)*
/ˈsɛr.voː/, *Latin, "servant" or "attendant."*

A terminal-based process manager and development launcher. Built with Go and Bubble Tea, **Servo** provides an interactive TUI for orchestrating complex workflows across monorepos or standalone projects. It manages process lifecycles, runs concurrent tasks with live output, detects port conflicts, and integrates with AI assistants for contextual debugging. Distributed as a pre-compiled binary, **Servo** serves as a unified entry point for development operations.

---

**Vigilo** *(verb)*
/ˈwi.ɡi.loː/, *Latin, "to watch, stay alert, keep aware."*

A lightweight task awareness overlay for development environments. **Vigilo** keeps tasks visible on top of your interface, helping with planning, focus, and follow-through. Designed to reduce context switching by keeping work-in-progress tasks persistently in sight.

---

**Dora** *(noun)*
/ˈdo.ra/, *inspired by "Dora the Explorer," the database explorer.*

A lightweight Tauri-native database management tool for developers. **Dora** provides private, local-first access to SQLite, LibSQL, Turso, and PostgreSQL databases. Designed for exploration and quick management, it allows developers to view, query, and manipulate data without leaving their desktop environment.

---

**Mutmar** *(noun)*
/ˈmʏt.mar/, *Frisian, "it must be done."*

A simple, no-nonsense todo application for developers and productivity enthusiasts. **Mutmar** focuses on capturing tasks quickly, tracking what needs attention, and helping you get things done without fuss.

---

**Zentjes** *(noun)*
/ˈzɛn.tjəs/, *Frisian-inspired, small amounts of money or loose change.*

A personal finance tracking application designed to help you stay aware of where your money goes. **Zentjes** focuses on simple expense logging, budget visibility, and day-to-day financial insight.

---

**Kiekje** *(noun)*
/ˈkik.jə/, *Dutch slang, "a quick snapshot or photo."*

A lightweight screenshot utility for quickly capturing moments on your screen. **Kiekje** focuses on speed and simplicity, making it easy to grab, save, and share screenshots without interrupting your workflow.

---

**Ynsjen** *(noun)*
/ˈɪn.sjən/, *Frisian, "to look into, inspect."*

A local-first developer menu for inspecting applications, data, and runtime behavior in real time. **Ynsjen** provides immediate visibility into running systems without context switching.
