# Profile: app

A desktop, web, or mobile application a person uses directly. This is the full shape;
skriuw and Papertrail are both apps.

Sections, in order:

1. header
2. pitch
3. badges
4. demo
5. body
6. usage, when the app has a flow worth walking through in order
7. install, only for desktop or self-hosted apps with a real install path
8. privacy, only if the app makes a checkable claim about data
9. development
10. footer

A web app with a single live URL drops Install and points at the URL from the body
instead, the way Papertrail does. Privacy is earned by having something true to say,
not by being an app.

A README that is only a body and a Privacy section reads thin. If the app has state
a user moves through (setup, daily use, a monthly close, an export), the usage
section walks that in order so the reader can picture a week with it.
