# Profile: library

A package someone installs into their own project: an npm/crates/pypi package, a
React hook, a Go module. No demo GIF unless the library is visual. No Privacy.

Sections, in order:

1. header
2. pitch
3. badges
4. body
5. install
6. development, only if contributors are expected
7. footer

The pitch is one line. The body has one paragraph at most and five
bullets at most. Install is one block per package manager the package is published
to, nothing else.
