# Profile: cli

A command-line tool or TUI. The demo GIF is a terminal recording and carries most of
the pitch, so record one before writing. No Privacy unless the tool phones home or
stores user data.

Sections, in order:

1. header
2. pitch
3. badges
4. demo
5. body
6. install
7. development
8. footer

Install gets one `###` per platform or package manager the tool ships through
(Homebrew, Scoop, AUR, cargo install, go install, a release binary). The demo caption
names the terminal and shell it was recorded in.
