# Usage

Only for apps with a flow: setup, repeated use, a close or export. Three to five
short paragraphs, in the order a user meets them, each naming a concrete control or
artefact (a calendar, a switch, a file). No sub-headings, no numbered list, no
screenshots.

This is not a feature list; the body already has one. Each paragraph explains a
consequence the bullets could not, such as what a closed month refuses to do, or
what an export contains.

Claims are checked against the code before writing. If a step cannot be verified,
leave it out.
