# Privacy

Profile-gated: only for a project that makes a real, checkable claim about data.
Being an app is not enough. A library never has this section.

Lead with the claim in bold, state what happens by default, and state where the data
lives and what a fresh install does over the network.

Then state the boundary honestly, including where it stops, and link the file in the
repo that proves it. Skriuw's admission that sync is not yet end-to-end encrypted is
the model. Close with what a reader who cares about that boundary should do instead.

If analytics exist, say what they collect, what they never collect, and how to turn
them off, the way Papertrail does. Do not write "we respect your privacy".
