# Development

The versions required, in one sentence, taken from `.tool-versions`, `.nvmrc`,
`rust-toolchain.toml`, `engines`, or CI. Then the three or four commands that
matter, each with a trailing comment saying what it does. Then one sentence linking
the deeper development doc, contributing, and security.

The closing sentence only names files that exist. Drop the `CONTRIBUTING.md` clause
or the `SECURITY.md` clause when the repo lacks them; drop the whole sentence when it
lacks all three. This sentence is the only place those two files are ever mentioned;
there is never a Contributing or Security section.

A library that does not expect contributors skips the section.
