# Pitch

What the thing is, written as a plain claim. The default is one line: a noun phrase
that names the category and the twist, such as "A commute log that ends in the
Excel sheet HR asks for". Add a second, third, or fourth line only when each one
carries a claim the reader needs before the badges, such as where it runs or what it
does not require. Four is the ceiling; it is not a target.

Break multi-line pitches by hand with `<br />` so the centering falls in a readable
shape. Each line is a complete claim, so a reader who stops after any line has
learned something true. Never pad a line to reach a count.

Whatever flows and fits the project wins over the template shape.
