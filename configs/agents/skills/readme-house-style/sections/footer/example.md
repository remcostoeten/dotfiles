The canonical footer. The shipped exemplars predate the `<small>` rule (dora writes
the license as a bare line, skriuw still carries a `## License` heading); this is
the shape to use.

```markdown
<br/>

xxx,<br/>
[Remco Stoeten](https://remcostoeten.com)<br/>
<small>MIT</small>
```

With a PS line:

```markdown
<br/>

xxx,<br/>
[Remco Stoeten](https://remcostoeten.com)<br/>
<small>MIT</small>

The vendored fonts are not covered by MIT; see [the font notices](src/assets/fonts/licenses/NOTICE.md).
```
