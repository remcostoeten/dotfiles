# Styling

Source of truth: `content/docs/guides/theming.mdx` and `content/docs/guides/icons.mdx`. Colors come from the Fumadocs theme imported in `src/app/globals.css`, with `site.theme.accent` on top.

## Accent color

```ts
theme: {
  accent: { light: "oklch(0.55 0.2 260)", dark: "oklch(0.75 0.15 260)" },
},
```

Sets the Fumadocs primary color for each mode. Any CSS color works, since the text color on top is chosen from its lightness. A color containing `;`, `{`, `}`, `<`, `>` or `\` is rejected and fails the build. `accent: null` keeps the neutral black theme. The CSS variables are generated by `src/shared/config/theme-css.ts` and injected in `src/app/layout.tsx`, so do not hand edit them.

Choose a light value dark enough for contrast on white and a dark value light enough for contrast on near black. When the user gives one color, derive both: keep the hue, lower lightness for light mode and raise it for dark mode.

## Radius

```ts
theme: { accent: null, radius: "1rem" },
```

One CSS length (`px`, `rem`, `em` or `0`). It is the size of the `xl` step, which cards, callouts and code blocks use. Other steps keep their proportion, so small elements scale down with it. `"0"` makes every corner square and `rounded-full` elements stay round. Leave it out for the default `0.75rem`.

## Logo

```ts
logo: { src: "/logo.svg", darkSrc: "/logo-dark.svg", width: 20, height: 20 },
```

- `src` and `darkSrc` take a path in `public`, a URL, inline SVG markup or a React component receiving `width`, `height` and `className`.
- `width` and `height` are the displayed size in pixels and are required.
- The site name stays next to the logo unless `hideName: true`. Then set `alt`.
- Inline SVG and components can use `currentColor` to follow the theme.
- Files go in `public/`, referenced from the root: `/logo.svg`, not `public/logo.svg`.

## Favicon

`favicon: "/favicon.svg"` or `favicon: { light: "/favicon-light.svg", dark: "/favicon-dark.svg" }`. Without it, an `icon.svg` or `icon.png` in `src/app` is used.

## Theme preset

In `src/app/globals.css`, swap the import `fumadocs-ui/css/black.css` for another file from `fumadocs-ui/css`, such as `neutral.css`, `ocean.css` or `emerald.css`.

## Individual colors

Override Fumadocs variables in `src/app/globals.css`, in `:root` for light and `.dark` for dark:

```css
:root {
  --color-fd-background: hsl(40 30% 98%);
}

.dark {
  --color-fd-border: hsl(0 0% 20%);
}
```

Use the `fd` tokens (`text-fd-foreground`, `bg-fd-background`, `border-fd-border`) in components, not hardcoded colors, so light and dark both work.

## Fonts

Set in `src/app/layout.tsx`. Replace `Geist` and `Geist_Mono` with another `next/font` family and keep the `--font-sans` and `--font-mono` variables.

## Layout sizes

`--topbar-height` (48px, 44px on small screens) and `--sidebar-width` (`min(22vw, 300px)`) in `src/app/globals.css`. The sidebar and top bar live in `src/modules/navigation`.

## Sidebar motion

Sections and folders share one spring, `duration: 0.35`, `bounce: 0`, set in `sidebar-navigation.tsx` and `navigation-nodes.tsx`. Keep them in sync if you change it.

## Icons

Icons are drawn as SVG in `src/shared/icons`, not loaded from an icon package. Set `icon: Rocket` in a page's frontmatter or a folder's `meta.json`.

Names: `BookOpen`, `Cloud`, `Compass`, `Download`, `FileText`, `Folder`, `GitHub`, `House`, `Lightbulb`, `Mail`, `Palette`, `Rocket`, `Route`, `Search`, `X`. An unknown name logs `[icons] Unknown icon "..."` and renders no icon.

To add one, draw a 24 by 24 component with `Glyph` in `src/shared/icons/icons.tsx`, add it to `namedIcons` (the key is the frontmatter name), and optionally add a hover motion in `motion.ts`. To use it inside MDX cards, register it in `src/modules/docs/mdx-components.tsx`. Hover motion only plays with a mouse and with reduced motion off.

## Code blocks and callouts

Shiki themes are `github-light` and `github-dark-default`, set under `rehypeCodeOptions` in `source.config.ts`. The block UI is `src/modules/docs/components/code-block.tsx` with `code-block.css`, callouts are `callout.tsx` with `callout.css`. Callout types: `info`, `warn` (or `warning`), `error`, `success`, `idea`.

## Rules

- Tailwind 4 with CSS first config. There is no `tailwind.config`. Theme tokens go in an `@theme` block in CSS.
- Merge class names with `cn` from `src/shared/helpers/cn.ts`.
- Modules meant to be copied into other projects use Fumadocs tokens only.
